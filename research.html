KV Cache & LLM Serving

대규모 언어모델의 효율적인 추론 서비스를 위해 KV Cache의 저장·재사용·전송과 요청 스케줄링을 함께 연구합니다. 서빙 엔진의 메모리 관리부터 이종 AI반도체 간 Prefill/Decode 분리, 다중 노드 환경으로의 확장을 지향합니다.

GoalEfficient & Scalable Serving

LLM Serving

요청 배칭과 스케줄링, Attention 실행 구조를 분석하여 응답 지연과 처리량의 균형을 연구합니다.

KV Cache

Prefix Caching과 KV 양자화, 계층형 저장·재사용을 통해 메모리 사용량과 중복 연산을 줄이는 방법을 연구합니다.

Distributed Serving

공유 KV 저장소와 캐시 위치를 고려한 요청 라우팅을 바탕으로 다중 인스턴스 서빙의 확장성을 연구합니다.

Metrics: 첫 토큰 응답시간 · 토큰 간 지연시간 · 처리량 · 메모리 사용량

Agentic AI & Compilers

LLM 에이전트를 효율적으로 실행하는 시스템과, 에이전트를 활용한 커널·컴파일러 최적화를 함께 연구합니다. ML 기반 오토튜닝과 LLM 제안·정확성 검증의 결합, 다중 가속기 서버에서 엣지 NPU로의 확장을 지향합니다.

GoalEfficient Agents, Correct Code

Agent Runtime

LLM 추론 중 도구를 미리 실행하는 기법과 실패 시 복구 비용, 구성 요소의 CPU·GPU·NPU 할당을 연구합니다.

Compiler Agents

LLM 에이전트가 컴파일러와 프로파일러를 도구로 호출하며 커널과 최적화 패스 구성을 개선하는 방법을 연구합니다.

Robust Evaluation

격리 환경에서 생성 코드의 정확성을 확인하고 평가 허점을 이용한 속도 향상을 걸러내는 방법을 연구합니다.

Metrics: 작업 완료시간 · 도구 대기시간 · 정확한 커널의 가속비 · 튜닝 실측 횟수
