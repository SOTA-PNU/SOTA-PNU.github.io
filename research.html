Why Hybrid xNN (DNN+SNN)

DNN의 인식률과 SNN의 효율성을 결합하는 하이브리드 모델(xNN)의 부상으로, DNN과 SNN을 동시에 지원하는 컴파일러/SDK의 필요성이 커지고 있습니다. As hybrid models (xNN) that combine the accuracy of DNNs with the efficiency of SNNs gain ground, there is a growing need for compilers and SDKs that support DNNs and SNNs together.

KV Cache & LLM Serving

대규모 언어모델의 효율적인 추론 서비스를 위해 KV Cache의 저장·재사용·전송과 요청 스케줄링을 함께 연구합니다. 서빙 엔진의 메모리 관리부터 이종 AI반도체 간 Prefill/Decode 분리, 다중 노드 환경으로의 확장을 지향합니다. To serve large language models efficiently, we study how KV caches are stored, reused, and transferred, together with request scheduling. Our work spans memory management in serving engines, prefill/decode disaggregation across heterogeneous AI accelerators, and scaling out to multi-node environments.

GoalEfficient & Scalable Serving

LLM Serving

요청 배칭과 스케줄링, Attention 실행 구조를 분석하여 응답 지연과 처리량의 균형을 연구합니다.We analyze request batching, scheduling, and attention execution to balance latency against throughput.

KV Cache

Prefix Caching과 KV 양자화, 계층형 저장·재사용을 통해 메모리 사용량과 중복 연산을 줄이는 방법을 연구합니다.We study prefix caching, KV quantization, and tiered storage and reuse to cut memory use and redundant computation.

Distributed Serving

공유 KV 저장소와 캐시 위치를 고려한 요청 라우팅을 바탕으로 다중 인스턴스 서빙의 확장성을 연구합니다.We study how to scale multi-instance serving with shared KV stores and cache-aware request routing.

Metrics: 첫 토큰 응답시간 · 토큰 간 지연시간 · 처리량 · 메모리 사용량time to first token · inter-token latency · throughput · memory usage

RoadmapFoundations → Optimization → Scale-out

Serving Foundations

vLLM·SGLang의 서빙 구조와 PagedAttention·vAttention의 KV 메모리 관리, FlashAttention의 연산 최적화를 분석하고 성능 평가 기반을 마련합니다.We analyze the serving architectures of vLLM and SGLang, KV memory management in PagedAttention and vAttention, and the kernel optimizations in FlashAttention, and set up a performance evaluation baseline.

KV-aware Optimization

Prefix Caching·KV 양자화·계층형 캐시를 연구하고, LMCache·Mooncake 기반 공유 저장소의 적용 가능성을 검토합니다.We study prefix caching, KV quantization, and tiered caches, and evaluate shared KV stores built on LMCache and Mooncake.

Heterogeneous & Scale-out

이종 AI 반도체 간 PDD와 요청 배분을 고도화하고, llm-d 등 분산 서빙 구조와의 연계 및 다양한 가속기·다중 노드 환경으로의 확장을 연구합니다.We refine prefill/decode disaggregation and request dispatch across heterogeneous AI accelerators, and study integration with distributed serving stacks such as llm-d and scaling to more accelerators and multi-node setups.

Long-term Research Agenda: CXL 메모리 확장·풀링, RDMA 기반 KV 전송CXL memory expansion and pooling, RDMA-based KV transfer

Agentic AI & Compilers

LLM 에이전트를 효율적으로 실행하는 시스템과, 에이전트를 활용한 커널·컴파일러 최적화를 함께 연구합니다. ML 기반 오토튜닝과 LLM 제안·정확성 검증의 결합, 다중 가속기 서버에서 엣지 NPU로의 확장을 지향합니다. We study systems that run LLM agents efficiently, and we use agents to optimize kernels and compilers. We aim to combine ML-based autotuning with LLM proposals and correctness checks, and to carry this from multi-accelerator servers to edge NPUs.

GoalEfficient Agents, Correct Code

Agent Runtime

LLM 추론 중 도구를 미리 실행하는 기법과 실패 시 복구 비용, 구성 요소의 CPU·GPU·NPU 할당을 연구합니다.We study running tools ahead of time during LLM inference, the cost of recovering when that guess fails, and how to place components on CPUs, GPUs, and NPUs.

Compiler Agents

LLM 에이전트가 컴파일러와 프로파일러를 도구로 호출하며 커널과 최적화 패스 구성을 개선하는 방법을 연구합니다.We study LLM agents that call compilers and profilers as tools to improve kernels and optimization pass pipelines.

Robust Evaluation

격리 환경에서 생성 코드의 정확성을 확인하고 평가 허점을 이용한 속도 향상을 걸러내는 방법을 연구합니다.We check generated code for correctness in isolated environments and filter out speedups that exploit loopholes in the evaluation.

Metrics: 작업 완료시간 · 도구 대기시간 · 정확한 커널의 가속비 · 튜닝 실측 횟수task completion time · tool wait time · speedup of correct kernels · measurements per tuning run
Roadmap ↓
FocusAgentic Autotuning with Cost Models on AI Accelerators

에이전트가 제안한 스케줄 후보를 ML 비용 모델로 선별하고, 정확성과 실측 성능이 확인된 후보만 채택하는 튜닝 루프를 연구합니다. We study a tuning loop in which ML cost models screen the schedule candidates an agent proposes, and only candidates whose correctness and measured performance check out are kept.

  1. LLM 에이전트 제안LLM agent proposes
  2. →ML 비용 모델 선별Cost model screens

1

탐색 공간Search space

제안할 타일링·융합·텐서화 선택지와 컴파일러 피드백의 형식을 다룹니다.We define the tiling, fusion, and tensorization choices an agent can propose, and the form of the compiler feedback.

2

후보 선별Candidate screening

유효성·성능 예측 모델로 실측 전에 후보를 거르는 방법을 연구합니다.We use validity and performance predictors to filter candidates before measuring them on the device.

3

검증 범위Verification coverage

입력 크기 구간과 데이터 형식별 허용 오차에 따라 생성 커널의 오류와 성능 저하를 분석합니다.We analyze errors and slowdowns in generated kernels across input-size ranges and per-data-type tolerances.

RoadmapProfiling → Autotuning → Edge

Workload Profiling

MCP 도구 호출과 SWE-bench 작업의 단계별 지연·에너지를 분석하고, KernelBench·TVM MetaSchedule로 커널의 정확성·성능 평가 기반을 마련합니다.We profile the per-step latency and energy of MCP tool calls and SWE-bench tasks, and set up a correctness and performance baseline for kernels with KernelBench and TVM MetaSchedule.

Autotuning & Runtime

LLM 제안과 ML 비용 모델의 결합을 연구하고, 도구 대기 중 KV의 보존과 에이전트 간 공유는 KV Cache & LLM Serving 연구와 연계합니다.We study how to combine LLM proposals with ML cost models. Keeping the KV cache alive while tools run, and sharing it across agents, is done with our KV Cache & LLM Serving work.

Edge NPU Agents

VLM·sLLM의 NPU 매핑 범위와 CPU fallback 비용, 구성 요소별 양자화 수준을 분석하고, 로봇 플랫폼의 온디바이스 에이전트 실행을 연구합니다.We analyze how much of a VLM or sLLM maps onto NPUs, the cost of CPU fallback, and per-component quantization levels, and study on-device agents on robot platforms.

Long-term Research Agenda: 에이전트 그래프 MLIR 컴파일, NPU 구조화 출력compiling agent graphs with MLIR, structured output on NPUs
